# 第三次全国土壤普查参考资料库

本目录用于集中管理“三普成果编制及质量控制主要参考资料”。

## 目录文件

- `manifest.json`：网站“参考文件”标签页使用的文件目录与分类信息。
- `archive.json`：完整资料包导入后自动生成，记录分块文件信息。
- `archive/`：完整 ZIP 资料包的分块数据。由于原始资料包约 310 MB，且其中单个 PPTX 超过 GitHub 普通仓库 100 MB 单文件上限，网站管理员通过“参考文件”页的一键导入功能将 ZIP 分块存入此目录。

## 网站使用

网站“参考文件”标签页会：

1. 按成果类别展示全部参考文件；
2. 支持文件名搜索；
3. 支持下载完整资料包；
4. 支持从资料包中提取并下载单个文件；
5. 在资料包尚未导入时提供管理员导入入口。

Office 临时锁文件（文件名以 `~$` 开头）不属于有效参考资料，未列入目录。
